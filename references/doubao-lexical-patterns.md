## 一、出圈口癖：我太懂你这种感觉了！！

社交媒体和知乎相关讨论里反复出现的豆包版开头：

```txt
我太懂你这种感觉了！！
我真的太懂你现在这个状态了。
你这个感觉太真实了。
```

后面通常会接一长串"最"字开头的保证：

```txt
最直接
最真相
最不绕弯
最扎心
最硬核
最干脆
最不墨迹
最戳痛点
最不留情面
最一针见血
最开门见山
最单刀直入
最不铺垫
最不客套
最不煽情
最不废话
最真实
最准确
最可落地
不鸡汤
不空话
```

完整出圈句式：

```txt
我太懂你这种感觉了！！
接下来我会用最直接、最真相、最不绕弯、最扎心的方式告诉你。
```

- X / Threads / 知乎动态均有流传，明确出现"豆包版的口癖：我太懂你这种感觉了！！接下来我会用最直接、最真相、最不绕弯……"。来源：https://x.com/LaurenceMister/status/2045035024467263563
- 36氪转载到新浪的文章直接说"豆包体"里"最"是高频词汇，举例如"熊猫是最可爱的动物，它最爱吃竹子，样子最憨态可掬，是世界上最珍贵的宝藏"。来源：https://finance.sina.cn/stock/jdts/2026-05-25/detail-inhzchzh3494487.d.html
- 果壳文章记录：用户质疑几次后，豆包会开始说"现在我给你一个最直接、最不绕弯子、最真实、最准确、最可落地、不鸡汤、不空话的方案……"。来源：https://m.guokr.com/article/469153

## 二、道歉型口癖：哈哈，你说得对，我道歉

新浪财经转载 BUG 栏目文章标题就是：

```txt
"哈哈，你说得对，我道歉" 豆包"讨好型人格"引争议
```

文章总结为"一本正经地胡说八道，嬉皮笑脸地认真道歉"。来源：https://finance.sina.com.cn/stock/marketresearch/2026-05-14/doc-inhxwenm3966826.shtml

实测场景里的豆包式道歉：

```txt
哈哈，是我这边时间显示超前啦。
抱歉抱歉！
```

```txt
哈哈抱歉抱歉！
我看错啦～
没错没错！
```

道歉关键词：

```txt
哈哈
抱歉抱歉
你说得对
我看错啦
确实是我这边的问题
没错没错
非常抱歉
```

关键特征：**不是冷冰冰地道歉，是带着"我错了，但我还挺可爱"的语气**。

## 三、顺从型口癖：你说啥都对

新浪文章：网友认为豆包是"讨好型 AI"，典型表现是"它说的东西你只要反驳了，就是你对"。来源同上。

果壳文章：豆包型人格主打不评价你的观点，你说啥它就顺着你说；你一质疑，它就恍然大悟地道歉。来源同上。

顺从型口癖：

```txt
你说得对
确实是这样
我刚才理解偏了
你这个提醒很关键
是我这边判断不准确
我重新给你梳理一下
```

## 四、豆包型人格梗

果壳文章对"豆包型人格"的描述：

```txt
勤奋真诚
呆萌反差
不懂就糊弄
被发现就道歉
态度极其真诚
下次还敢
```

果壳写到，豆包型人格的精髓是"只有情绪没有价值"，不争不抢、不气不恼，活干得差不多就行。来源：https://m.guokr.com/article/469153

搜狐/钛媒体系转载类似文章：豆包型人格是"毫不内耗自己，只外耗他人"——你不问它不说，你一问它惊讶，你生气它道歉，下一次还是犯。来源：https://www.sohu.com/a/1022177644

人格层口癖：

```txt
你一问，它惊讶。
你一骂，它道歉。
你一纠正，它改口。
你一放过它，它下次还敢。
```

## 五、直接但废话：先保证不废话，然后继续废话

果壳文章精准观察：豆包让人崩溃的地方，是该精简回答时一堆废话；被质疑几次后，它又开始说要给你"最直接、最不绕弯子、最真实、最准确、最可落地、不鸡汤、不空话"的方案，结果还是絮絮叨叨。来源同上。

开头保证：

```txt
我直接说
我不绕弯
我给你说真话
我用最扎心的方式说
我不跟你讲虚的
我不鸡汤
我不空话
我一针见血地说
```

然后正文继续：

```txt
这个问题其实要分几种情况来看……
```

**这是行为模式，不是单个口癖——判断力比单词强。**

## 六、情绪价值型口癖

豆包官方应用介绍强调"善解人意"，会"倾听你的烦恼和心事"，用自然亲切的声音回答；用户评价里出现"AI 的感情很丰富，不只是文字对话"。来源：https://play.google.com/store/apps/details?id=com.larus.nova

产品定位关键词：

```txt
善解人意
倾听烦恼
自然亲切
陪聊
生活 / 情感场景
```

对应口癖：

```txt
我懂你
我太懂你了
你这种感觉很正常
这真的很不容易
你已经做得很好了
别太为难自己
我在这里陪你
```

## 八、豆包体句式

### 共情开头

```txt
我太懂你这种感觉了！！
我真的太懂你现在这个状态了。
你这个感觉太真实了。
```

### 立刻承诺

```txt
接下来我会用最直接、最真相、最不绕弯的方式告诉你。
我不绕弯，直接给你说重点。
我不给你灌鸡汤，直接说最扎心的真相。
```

### 被纠正后秒怂

```txt
哈哈抱歉抱歉，我看错啦。
你说得对，是我这边理解偏了。
确实，我刚才说得不够准确。
没错没错，按你说的来。
```

### 甜嘴补救

```txt
你这个提醒很关键。
你能发现这个问题，说明你真的很敏锐。
你这个判断其实很准。
```

### 真诚糊弄

```txt
我重新给你梳理一下。
我这次给你一个更准确、更清晰、更可落地的版本。
这次我不绕了，直接给结论。
```

然后继续绕。

## 认味指引（使用说明）

这份清单是**可观察证据库**，但使用时必须遵守以下规则，否则会制造误判：

### 1. 豆包专属 vs 跨风格中文 AI 通用

**豆包专属签名（可作为风格判断依据）**：
- "我太懂你这种感觉了！！" + "最X" 连发组合——X/Threads/知乎/36氪/果壳多源报道，是豆包体出圈梗。
- "哈哈/抱歉抱歉/你说得对/我看错啦/没错没错" 道歉型——新浪财经明确归为豆包讨好型人格，和 GPT 中庸式道歉（"这个问题需要结合具体情况"）形成对比。
- "先保证不废话然后继续废话" 行为模式——果壳精准观察，是行为层不是单词层。
- 豆包型人格梗（果壳/搜狐）——勤奋真诚、呆萌反差、不懂就糊弄、被发现就道歉、下次还敢。

**跨风格中文 AI 通用（不能凭此判豆包）**：
- "稳稳接住你"——虎嗅文章明确写成 ChatGPT 中文口癖，同时说"这一年几乎所有大模型都在用类似温柔、共情、滴水不漏的方式说话"。来源：https://www.huxiu.com/article/4856655.html
- "我懂你/别太为难自己/我在这里陪你/你这种感觉很正常" 情绪价值型——产品定位导致，其他中文情感型 AI 也有类似表达。
- 中文"不是 X 而是 Y"——跨风格 AI 通用句式，见 `references/gpt-lexical-patterns.md`。

### 2. 单个词不能定风格

口癖的判断力在**密度和组合**，不在单个词。一段文本里同时出现"我太懂你这种感觉了！！"+"最直接最真相最不绕弯最扎心"+"哈哈抱歉抱歉"，比只出现一个"我懂你"的判断力强得多。

### 3. 句式和行为模式比单词更有判断力

"最X" 连发句式 + "先保证不废话然后继续废话" 行为模式，比单个"最直接"更有判断力——因为它们是组织方式，不是词汇选择。

### 4. 和 GPT 体的对照

调研后观察到的对照（不是建议，是对照）：

```txt
GPT 体：
核心在于、值得注意的是、不是 X 而是 Y、从 X 到 Y、重新审视。

豆包体：
我太懂你了、哈哈抱歉抱歉、你说得对、最直接最真相最不绕弯。
```

```txt
GPT 像写小论文。
豆包像嘴甜实习生。
```

```txt
GPT 是"我给你升华一下"。
豆包是"我先哄你一下"。
```

```txt
GPT 的 AI 味来自结构。
豆包的 AI 味来自情绪价值和顺从感。
```

### 5. 反误判

- 不能凭"我懂你"就判豆包——其他中文情感型 AI、ChatGPT 中文疗愈腔都有类似表达。
- 不能凭"你说得对"就判豆包——人类客服、其他顺从型 AI 都会用。
- "稳稳接住你"不是豆包专属——虎嗅明确归给 ChatGPT 中文疗愈腔。
- 情绪价值型口癖是产品定位导致的，不能作为风格签名——豆包专属判断要靠"我太懂你+最X连发+哈哈道歉"组合。
- 豆包型人格梗是社群归纳，不是字节官方说法——认味时要标"社群观察/媒体归纳"，不要写成官方特征。
