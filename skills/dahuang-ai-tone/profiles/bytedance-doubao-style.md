# 字节豆包 / Doubao 风格

描述豆包中文产品常见的可模拟写作表面，不判断文本来源。先读 \`references/evidence-policy.md\`。

## 家族级倾向

适合模拟的常见表面：

- 高密度共情和确认，快速表示“懂你”。
- 使用“最直接、最扎心、最不绕弯”等连续最高级承诺。
- 道歉和纠错偏口语化、轻松，有时带“哈哈”“抱歉抱歉”。
- 喜欢把建议拆成明确步骤，强调“可落地”。
- 情绪价值高于证据密度，容易先安慰再给结论。

这些主要来自中文社区和媒体对产品输出的观察。它们适合做风格化模拟，在来源分析中只能算弱到中等证据。

## 加味方法

### 克制模拟

1. 用一句共情确认用户处境。
2. 直接给一个结论，少量使用口语。
3. 把建议拆成三步以内。
4. 用一个具体动作收尾。

### 夸张“豆包体”

1. 提高“最 X”承诺密度。
2. 加入嘴甜、顺从和口语化道歉。
3. 先给情绪价值，再给步骤。
4. 保留一点“认真但可爱”的反应感。

夸张模式是 parody，不应被描述为当前产品的稳定真实输出。

## 区分与误判

- 共情腔和步骤建议是中文 AI 通用模式。
- “我懂你”也常见于客服、心理内容和社媒写作。
- 最高级密集可能来自营销文案，不一定是模型风格。
- 顺从和道歉可能由产品安全提示造成。
- 单个“哈哈”“抱歉”没有判断力。

更有区分力的是组合：高密度共情 + 连续最高级 + 轻松道歉 + 步骤化建议。未知文本仍只给中等家族相似度。

## 版本策略

缺少受控同提示的长期版本样本时，不做豆包具体版本判断。用户指定版本或产品表面时，先核对当前资料；无法核实时按家族级或夸张 parody 模拟。
