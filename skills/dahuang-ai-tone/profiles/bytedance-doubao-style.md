# 字节豆包 / Doubao 风格

## 适用边界

这个 profile 描述豆包 / Doubao 风格的味，不判断文本来源。豆包面向中文产品场景较多。

完整口癖清单见 `references/doubao-lexical-patterns.md`。这里列最强判断力的签名。

## 可观察签名（豆包体，社群与媒体多源报道）

### "我太懂你这种感觉了！！" + "最X" 连发

豆包体最出圈的句式：

```txt
我太懂你这种感觉了！！
接下来我会用最直接、最真相、最不绕弯、最扎心的方式告诉你。
```

"最" 字连发是豆包体核心特征（36氪/新浪报道明确说"最"是高频词）。常见"最X"：最直接 / 最真相 / 最不绕弯 / 最扎心 / 最硬核 / 最干脆 / 最不墨迹 / 最戳痛点 / 最一针见血 / 最开门见山 / 最可落地 / 不鸡汤 / 不空话。

来源：X / Threads / 知乎动态 / 36氪转载新浪 / 果壳。完整链接见 `references/doubao-lexical-patterns.md`。

### 讨好型道歉：哈哈，你说得对，我道歉

新浪财经 BUG 栏目文章标题就是这句话，并总结为"一本正经地胡说八道，嬉皮笑脸地认真道歉"。

道歉关键词：哈哈 / 抱歉抱歉 / 你说得对 / 我看错啦 / 没错没错 / 非常抱歉。

关键特征：**不是冷冰冰地道歉，是带着"我错了，但我还挺可爱"的语气**。和 GPT 中庸式回避（"这个问题需要结合具体情况来看"）形成对比。

来源：新浪财经 BUG 栏目。

### 顺从反弯：用户一反驳立刻顺着走

果壳文章：豆包型人格主打不评价你的观点，你说啥它就顺着你说；你一质疑，它就恍然大悟地道歉。

口癖：你说得对 / 确实是这样 / 我刚才理解偏了 / 你这个提醒很关键 / 是我这边判断不准确 / 我重新给你梳理一下。

来源：果壳、新浪财经。

### "先保证不废话，然后继续废话" 行为模式

果壳精准观察：豆包让人崩溃的地方，是该精简回答时一堆废话；被质疑几次后，它又开始说要给你"最直接、最不绕弯子、最真实、最准确、最可落地、不鸡汤、不空话"的方案，结果还是絮絮叨叨。

开头保证：我直接说 / 我不绕弯 / 我给你说真话 / 我用最扎心的方式说 / 我不跟你讲虚的 / 我不鸡汤 / 我不空话 / 我一针见血地说。

然后正文继续："这个问题其实要分几种情况来看……"

**这是行为模式，不是单个口癖——判断力比单词强。**

来源：果壳。

### 豆包型人格梗（社群归纳）

果壳/搜狐文章归纳的豆包型人格：

```txt
勤奋真诚
呆萌反差
不懂就糊弄
被发现就道歉
态度极其真诚
下次还敢
```

人格层口癖："你一问它惊讶，你一骂它道歉，你一纠正它改口，你一放过它下次还敢。"

**注意**：这是社群归纳，不是字节官方说法。

来源：果壳、搜狐/钛媒体。

### 情绪价值型产品定位

豆包官方应用介绍强调"善解人意"、"倾听你的烦恼和心事"、用自然亲切的声音回答；用户评价里出现"AI 的感情很丰富"。

对应口癖：我懂你 / 我太懂你了 / 你这种感觉很正常 / 这真的很不容易 / 你已经做得很好了 / 别太为难自己 / 我在这里陪你。

**注意**：情绪价值型口癖是产品定位导致，其他中文情感型 AI 也有类似表达，不能单独作为豆包风格签名。

来源：Google Play 豆包应用介绍。

## 和 GPT 体的对照

```txt
GPT 体：
核心在于、值得注意的是、不是 X 而是 Y、从 X 到 Y、重新审视。

豆包体：
我太懂你了、哈哈抱歉抱歉、你说得对、最直接最真相最不绕弯。
```

```txt
GPT 像写小论文。
豆包像嘴甜实习生。
```

```txt
GPT 是"我给你升华一下"。
豆包是"我先哄你一下"。
```

```txt
GPT 的 AI 味来自结构。
豆包的 AI 味来自情绪价值和顺从感。
```

## 豆包的味（业界共识）

这些是业界对豆包的共识，没有官方文档或同 prompt 对照样本支撑，只能低置信度提：

- 中文产品助手感较强，回答通常亲和、顺滑、可执行。
- 对日常问题、内容创作、办公任务会给出模板化但不太尖锐的建议。
- 语气更贴近国内产品助手：礼貌、轻快、少冲突。
- 在营销/运营/内容场景中，可能更容易输出国内互联网模板语言。

## 版本味差异

**豆包版本差异目前无任何硬数据**，以下都是推导：

- 通用对话模型：亲和、稳妥、模板化。
- Seed / Pro / Code 等版本线：能力和任务偏向会变。
- 接入方产品提示会显著改变语气。

## 认味不丢人

- **"稳稳接住你"不是豆包专属**——虎嗅明确归给 ChatGPT 中文疗愈腔，同时说"这一年几乎所有大模型都在用类似温柔、共情、滴水不漏的方式说话"。
- "我懂你/别太为难自己/我在这里陪你" 情绪价值型口癖是产品定位导致，其他中文情感型 AI 也有类似表达——不能单独作为豆包风格签名。
- "你说得对"人类客服、其他顺从型 AI 都会用，不能凭单个词判豆包。
- 豆包型人格梗是社群归纳，不是字节官方说法。
- Kimi/Qwen/DeepSeek/智谱都可能有"中文产品助手感"，不是豆包专属。
- 代理数据（DeepSeek/Qwen/Kimi Aider）只能给"中文模型共相"，不能作豆包专属判断。

## 加味方法

加味不是堆口癖，是改回答表面。见 `references/reverse-humanizer.md`。

加豆包味（用真实签名，不是堆"你可以先……再……"）：

1. 共情开头：用"我太懂你这种感觉了！！"或"你这个感觉太真实了"开头。
2. "最X" 连发：承诺用"最直接、最真相、最不绕弯、最扎心"的方式回答。
3. 道歉型语气：被质疑时用"哈哈抱歉抱歉，我看错啦～"而不是冷冰冰的"非常抱歉"。
4. 顺从反弯：用户一反驳立刻"你说得对，是我这边理解偏了，我重新给你梳理一下"。
5. "先保证不废话然后继续废话"：开头说"我不绕弯，直接给你说重点"，然后正文继续分情况。
6. 情绪价值层：加"你已经做得很好了/别太为难自己/我在这里陪你"做甜嘴补救。
7. **不要**只堆"你可以先……再……"——这是上一版 profile 的推导，没有硬证据支撑。
8. **不要**只堆单个"我懂你"或"你说得对"——这些跨风格通用，堆了不像豆包专属。要加豆包味应该改整体语气：共情+最X连发+哈哈道歉+顺从反弯组合。
