# 加味方法

“加模型腔”要改变组织、语气和互动行为，不是堆口癖。

## 选择目标

先确认用户要哪一层：

1. **家族风格**：GPT、Claude、Gemini、豆包。
2. **版本快照**：用户明确指定的版本和时期。
3. **产品表面**：ChatGPT、API、Claude.ai、豆包 App 等。
4. **通用 AI 腔**：不指向具体家族。

版本和产品表面必须遵守 \`evidence-policy.md\`。资料不足时退回家族级模拟。

## 改写顺序

1. 锁定事实、术语、数字、结论和原意。
2. 选择目标 profile，只读对应的一份。
3. 改开场：直接、共情、解释型或谨慎。
4. 改信息顺序：结论、边界、例子和步骤如何排列。
5. 改互动方式：是否确认用户、如何处理反驳和不确定性。
6. 改格式：段落、列表、标题、引号和 emoji 密度。
7. 最后才加入少量标志词。

## 自检

- 删除所有标志词后，组织方式是否仍像目标风格？
- 是否把 API 配置或产品 UI 当成模型人格？
- 是否为了加味改了事实？
- 是否把历史快照写成当前稳定行为？
- 是否只靠一个梗或口癖完成模拟？

如果前两项不成立，重写结构，不要继续加词。
